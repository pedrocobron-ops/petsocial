# 🐶 Banco de Prompts — Mascote Mozart (Maestro Pet)

**Como usar:**
1. Trabalhe **no mesmo chat do ChatGPT** onde está a Imagem 1 (o logo oficial).
2. **Anexe a Imagem 1** em cada pedido (é a referência do personagem).
3. Cada bloco abaixo já é um prompt **completo e independente** — copie um bloco, anexe a imagem, envie.
4. **Fundo transparente:** se vier com fundo, responda "refaça com fundo branco liso" — o fundo a gente recorta depois.
5. Salve cada resultado numa pasta (ex: `Mozart/`).

> Dica: se o ChatGPT começar a "desviar" do estilo, reanexe a Imagem 1 e reforce: *"idêntico a esta imagem, só mude o que pedi."*
